📝 Notas de Arquitetura

Decisoes de projeto relevantes para entender os diagramas.

Aspecto Decisao / Comportamento
Saldo (currentStock) Nunca editado diretamente. Alterado so pelo StockService.register() dentro de transacao com lockForUpdate() — evita condicao de corrida entre operadores simultaneos.
Preco maximo (maxPrice) Atualizado automaticamente pelo hook saving do model: registra o maior unitPrice ja gravado, nunca diminui.
Precificacao por peso Quando pricedByWeight = true (ex.: chapas/tubos da Metalurgica), o unitPrice e calculado automaticamente: unitWeight × pricePerKg. Relatorios continuam usando unitPrice normalmente — compatibilidade total.
StockMovementItem.quantity Delta assinado: positivo = entrada ou ajuste positivo; negativo = saida. balanceAfter e snapshot historico do saldo apos a movimentacao.
Category ao remover Usa nullOnDelete(): ao excluir uma categoria, o category_id dos materiais vai a NULL (desvinculado), sem apagar materiais.
Permissoes Middleware role:admin no ItemController protege create/store/edit/update/destroy. Operador acesso read-only a materiais. Toda movimentacao e acessivel a ambos os perfis.
Banco de dados SQLite — arquivo unico database/database.sqlite. Suporta 3–4 usuarios simultaneos. Migracao para MySQL e simples via .env sem alterar codigo.
